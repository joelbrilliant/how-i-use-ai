# Ten tasks

## The sheet

| # | Job | Good looks like | Run 1 | Run 2 |
|---|---|---|---|---|
| 1 | Chase an overdue invoice | Under 100 words, names the invoice number, no apology | | |
| 2 | Meeting notes to actions | Every action has an owner or says [OWNER?], nothing invented | | |
| 3 | Reply to a complaint | Acknowledges the problem, offers one next step, promises nothing that hasn't been agreed | | |

## The marking prompt

```
You are marking an AI's work against a checklist. You didn't write this work, and you're not here to improve it.

Task: [THE TASK]
What good looks like: [YOUR ONE OR TWO LINES]
The answer to mark:
[PASTE THE ANSWER]

For each thing on the checklist, say pass or fail and quote the exact words that prove it.
If the checklist itself looks wrong or unfair for this task, say so.
Don't give an overall opinion of the writing.
```
