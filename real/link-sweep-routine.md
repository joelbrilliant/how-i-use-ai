# Daily link sweep, a routine's instructions

A daily routine from Routines, with the two fixes from its first run in. Bits that only make sense on my machine are taken out.

```
Name: Daily link sweep. Once a day at 5.13am, Brisbane time.

Read the last 24 hours of every bot's chat, and only my own messages in them.

For each link I shared to keep or come back to, save it to my notes store:
- with the date of my message, not today's date
- with my reason only if I gave one, in my exact words
- leave the reason out if I gave none, and don't guess one

Skip links for the task in hand, any bot's own links, and anything I've marked private.
Don't open a link just to summarise it. This routine saves and nothing else.

Quiet when there's nothing to save. Otherwise add one line to the Wednesday digest with the count.
No message to me, and nothing else written.
```
