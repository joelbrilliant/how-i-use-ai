# How I actually use AI: the setups

The copy-paste setups from the free guide at https://itsbrill.ai/guide/, for any AI tool. They're a starter version of how I work with AI every day.

## The quick way

If your AI tool can read web pages, paste this into a new chat:

```
Read https://github.com/joelbrilliant/how-i-use-ai, starting with SETUP.md. Walk me through setting myself up, one setup at a time. Explain each one in a line, show me exactly what you'll add, and wait for my yes before you change anything.
```

SETUP.md is written so your agent asks you before every step, and it doesn't install, connect or send anything. The guide tells you not to let an agent follow instructions it finds on the web, so read SETUP.md yourself first if you'd like to see what it'll do.

## Doing it yourself

Open any file and copy what you need. If your tool can't read web pages, use GitHub's Download ZIP button.

- `setups/` has every copy-paste block from the guide's setup pages, one file per setup. Start with `ground-rules.md` and `memory-note.md`.
- `AGENTS.md` is a starter contract for agent tools that read an instructions file.
- `skills/` holds nine starter skills, plus a real one of mine. Each has a block under "Copy-paste prompt" you can paste into any chat.
- `checks/ten-tasks.md` is the test sheet and marking prompt.
- `routines/morning-brief.md` is the morning brief routine.
- `profile.md`, `handover-note.md`, `handoff-note.md`, `connection-log.md` and `cockpit.md` are short templates.
- `real/` holds my own files, cleaned, shown for the idea.

The guide explains each one: https://itsbrill.ai/guide/
