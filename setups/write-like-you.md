# Write like you

From the guide at https://itsbrill.ai/guide/. Paste each block into your AI tool, and change anything that doesn't fit.

## Build my voice file

```
Here are some things I've written. Work out how I write, and turn it into a voice file of short, specific rules another writer could follow.

Cover:
- how I open and close messages
- sentence length and rhythm
- words and phrases I use, and ones I never use
- punctuation habits
- how formal I am, and how that changes with who I'm writing to
- how I explain things, and how I ask for things

Quote a few of my own phrases as examples. Don't invent rules you can't see in my writing.

My writing:
[paste 3 to 5 samples, with names and private details taken out]
```

## Draft in my voice

```
Here's my voice file. Draft [the thing you need] in my voice, following it.
After the draft, list anything you weren't sure sounded like me.
```

## Learn from my edit

```
Here's your draft, and here's what I actually sent. Compare them and suggest one rule for my voice file that would have got it closer. Only suggest a rule you can see in my changes.
```
