# Prompting techniques

From the guide at https://itsbrill.ai/guide/. Paste each block into your AI tool, and change anything that doesn't fit.

## Write the prompt, then answer it

```
Write me a prompt for [the topic or task]. Then answer that prompt.
```

## Write the prompt and wait

```
Write me a prompt for [the topic or task]. Show me the prompt, and wait for me to change it or say go before you answer it.
```

## Talk about one part

```
Rewrite only this part. Leave everything else as it is.
Why did you say this? What's it based on?
Make this shorter, and keep the meaning.
Give me two other ways to say this.
This is wrong. Here's what's actually true: [the fact]. Fix this part and anything that depends on it.
```

## Plan first

```
Before you start, give me a short plan: the steps you'll take and what you'll produce. Wait for my go before you do the work.
```

## Three versions

```
Give me three different versions of this, each taking a different approach. Then tell me which one you'd pick and why.
```

## Check before handing over

```
Before you give me the final version, check it against these and fix anything that fails:
1. [it's under N words]
2. [it mentions X]
3. [it doesn't promise anything we haven't agreed]
Then show me the final version, and tell me which checks you had to fix.
```

## Explain it at my level

```
Explain [the topic] to someone who [is new to it / runs a small business / has five minutes]. Use one everyday example. Then tell me the one thing most people get wrong about it.
```

## Where are we

```
Sum up where we are in five lines: what we've decided, what's still open, and what's next. Only include what we actually agreed.
```
