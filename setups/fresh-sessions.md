# Fresh sessions

From the guide at https://itsbrill.ai/guide/. Paste each block into your AI tool, and change anything that doesn't fit.

## The handover note

```
Write me a handover note I can paste into a fresh chat:
- what we're working on, in one line
- where we got to
- the decisions so far, and why
- what's still open or unsure
- what to do next
Only include what was actually said or decided here. Keep it short.
```

## Warn me when it's time

```
If a chat gets long, changes topic, or you notice you're losing track of earlier details, tell me it's time for a fresh chat and offer to write a handover note.
```

## Pick up from a handover

```
Here's a handover note from an earlier chat. Read it, tell me in two lines where we are and what's next, and ask me anything that's unclear before you carry on.
```
