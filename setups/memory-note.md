# A memory that works

From the guide at https://itsbrill.ai/guide/. Paste each block into your AI tool, and change anything that doesn't fit.

## Set up my memory note

```
I want to set up a memory note you'll read at the start of our chats. Interview me first. Ask up to 10 short questions, one at a time, about my role, my work, who I write for, how I like things done, what I'm working on and what annoys me.

Then write the note in plain language, under one page, with these sections:
- About me
- How I like things (tone, format, length, what to avoid)
- Current work
- Decisions, each with today's date
- Open loops (things waiting on me or someone else)
- Never (things you must not do)

Only include what I told you. Don't add anything you've guessed about me.
```

## Update my memory note

```
Here's my memory note. Before we finish, update it from this chat.
- Add any decision I made, with today's date.
- Add new open loops, and remove any that are now done.
- Add any preference I stated about how I like things.
Only add things I said or decided in this chat. Don't add anything you've guessed.
Keep it under one page. Give me the whole updated note, then list what you changed.
```

## Start with my memory note

```
Here's my memory note. Read it, then tell me in one line what you'll keep in mind for this chat.
```

## Tidy my memory note

```
Here's my memory note. Remove anything finished or out of date, merge anything repeated, and keep it under one page. Give me the whole note, then list what you removed and why.
```
